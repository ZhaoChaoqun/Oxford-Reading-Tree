# Reading companions

72 books: **36 L1 + 36 L2**, with **144 PDFs + 72 editable Markdown files**.
These companion files are counted separately from the original library media.

- **landscape.pdf**: the main daily co-reading edition, A4 landscape with 7 mm
  margins and complete physical book openings; 1109 pages across 72 books.
- **portrait.pdf**: the paper-saving edition, A4 portrait, at most two complete
  image/text groups per page; long groups may occupy a page or continue with the
  complete image. 568 pages across 72 books.
- **companion.md**: an unchanged copy of the latest corrected landscape companion
  text, not the older portrait Markdown. Titles inside the delivered content may
  retain different punctuation from the original library filenames.

Use A4 paper at 100% scale, selecting the orientation for the chosen edition.
The PDFs include the original book images; the Markdown is editable text only.
Original image copyright marks have not been removed or altered.

## Files and versions

Each directory uses the exact original PDF filename without its extension.
The [manifest](manifest.json) records catalog IDs, original book/audio paths,
companion paths, page counts, SHA-256 checksums, byte sizes, and edition dates.
All manifest paths are relative to the repository root. Checksums and sizes
refer to actual file bytes, not Git LFS pointers. The landscape/text edition is
dated 2026-09-09; the portrait edition is dated
2026-09-08.

The 144 PDFs total **478,551,844 bytes**
(approximately 478.55 MB) and use the existing
Git LFS rules. See [download instructions and LFS quota information](../README.md#download-the-actual-media).
To retrieve just these PDFs after configuring Git LFS:

```sh
git lfs pull --include="Companions/**/*.pdf" --exclude=""
```

This is a file archive and documentation integration only. It does not add
companion controls to the app or change its `/__local-media` routes.
Original `L1/` through `L9/` book/audio paths remain unchanged.
Base64 HTML, videos, subtitle/OCR/ASR sources, extracted images, old samples,
and intermediate artifacts are not included.
